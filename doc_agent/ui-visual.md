# 界面视觉

本文定义**视觉语言、取值归属与判断规则**，不重复代码里已经写死的组件取值。
具体颜色令牌在 `resources/base|dark/element/color.json`，动效在 `utils/UiMotion.ets`，
工具条几何在 `services/ToolbarContract.ets`；
页面骨架、组件职责与交互触发见 [`ui-framework.md`](ui-framework.md)，
资源机制见 [`arkts-conventions.md`](arkts-conventions.md)。

视觉层的目标只有两个：**让内容清楚**，**让远控画面不被界面抢走**。

## 1. 设计定位

**晴空纸鸢**。品牌取自风筝：线是连接，风筝是远端桌面；界面本身保持安静。

| 原则 | 含义 | 落点 |
|---|---|---|
| 清 | 内容优先，层级少而明确 | 单主操作、实心内容面、弱装饰 |
| 稳 | 远控场景可预期、不跳动 | 固定几何、克制动效、状态不只靠颜色 |
| 轻 | 界面退到画面之后 | 玻璃只用于浮层，列表与表单不铺材质 |

软件特色收敛在三处：

- **品牌标记**：应用图标与协议标记；风筝母题只存在于图标，不做背景装饰。
- **协议强调色**：RDP 蓝、Moonlight 紫，只用于协议图标、页签、运行徽标。
- **会话遥测**：等宽数字、暗玻璃工具条，强调“远控仪表”而不是游戏 HUD。

不采用：霓虹发光、满屏毛玻璃、彩色阴影、渐变堆叠、所有控件胶囊化、把图标当插画。

## 2. 取值归属

视觉文档定义角色与规则；具体成员由代码与资源承担。**同一事实不写两遍。**

| 内容 | 家 |
|---|---|
| 颜色令牌与深浅值 | `resources/base|dark/element/color.json`；代码只用 `$r('app.color.*')` |
| hover/press/浮层时长与曲线 | `utils/UiMotion.ets` |
| 会话工具条高度、圆角、触发区 | `services/ToolbarContract.ets` |
| 组件局部间距、圆角、字号、图标尺寸 | 组件文件内的取值；共享值用常量 |
| 提示/确认/通知外壳 | `components/PromptDialog.ets` |
| 页面骨架、组件职责、交互触发 | [`ui-framework.md`](ui-framework.md) |

约束：

- `.ets` 中不写十六进制颜色。
- 同一几何值被 3 个以上组件复用时，提升到该领域已有文件，不新建平行令牌文件。
- 新增视觉值先判断它属于颜色、动效、工具条还是组件局部，再写到对应的家；本文只记录角色与判断依据。

## 3. 色彩语言

### 3.1 品牌色

品牌蓝来自应用图标。交互填充比图标蓝更深，以承载白字；图标蓝本身只作品牌标记，不作白字按钮底。

| 角色 | 用途 | 判据 |
|---|---|---|
| 品牌填充 | 主按钮、选中态、FAB | 需要白字或白色图标 |
| 品牌文字 | 链接、激活图标、浅色强调 | 需要品牌色但不需要填充 |
| 品牌浅底 | 选中行、chip、次级强调 | 需要弱化但不失品牌 |
| 品牌标记 | 应用图标、协议标记渐变 | 只用于 40/44vp 方形标记 |

`brand_mark_end` 与白字对比度不足，不用于按钮填充。

### 3.2 中性色

中性色使用系统语义角色，不按组件另造灰阶：

`canvas` / `surface` / `surface_subtle` / `surface_sunken` / `surface_elevated` /
`control_bg` / `border` / `control_border` / `divider` / `text_primary` / `text_secondary` /
`text_tertiary` / `text_disabled`。

- 浅色画布是浅灰，卡片是白色；深色画布是系统黑，卡片是深灰，不用墨蓝底。
- 文字层级只允许 primary / secondary / tertiary / disabled 四档；不要用透明度临时造第五档。
- 分隔线弱于描边；能用留白分开时优先不加分隔线。
- 次级控件（次级按钮、未选 chip、中性圆钮）使用 `control_bg` + `control_border`；`surface_subtle` 只用于输入与内容底，避免控件与白色卡片同色。

### 3.3 语义色与协议色

- 成功、警告、危险各有独立色与浅底；普通提示复用品牌色。
- 危险色只用于删除、断开、错误；能力限制用警告色，不用危险色。
- RDP 用品牌蓝，Moonlight 用紫色；紫色只出现在协议图标、页签、运行徽标，不铺大表面。
- 状态不只靠颜色：徽标带文字，错误带图标或文案。

### 3.4 会话 chrome

会话工具条与状态卡**不随主题变**，始终暗玻璃。原因是它们覆盖在任意视频画面上，浅色 chrome 会在亮画面上失去边界。

- 工具条/状态卡用暗玻璃底、白色主文字、半透明白次文字。
- 遥测正常用次级白，警告用琥珀，告警用红。
- 会话页根容器使用暗色实心底，避免工具条与画面之间出现浅色缝隙。
- 工具条按钮不是透明文字：默认中性 tonal（`chrome_control_bg` + `chrome_control_border`），危险动作用危险 tonal（`chrome_danger_bg` + `chrome_danger_border` + `chrome_danger`），激活态用强调 tonal（`chrome_accent_bg` + `chrome_accent_border` + `chrome_accent`）。
- `chrome_*` 在 base 与 dark 中同值，不复用页面语义色。

## 4. 表面与层级

| 层 | 材质 | 判据 |
|---|---|---|
| 页面底 | 渐变或壁纸+遮罩 | 不承载正文 |
| 内容面 | 实心 `surface` + 1px 描边 + 轻阴影 | 表单、列表、连接行 |
| 行 | 轻卡片：实心 + 描边 + 轻阴影；hover 抬升 | 需要与页面底分开 |
| 页头 | 玻璃 + 底部分隔 | 唯一常驻玻璃 |
| 会话工具条/状态卡 | 暗玻璃 + 描边 | 覆盖视频 |
| 菜单 | 系统组件默认 | 不自定义颜色与圆角 |
| 提示/确认/通知 | `PromptDialog`：实心 `surface` + 1px 描边 + `shadow_2` + 20 圆角 | 所有自定义提示窗复用同一外壳 |
| Toast | 系统 Toast + 暗色 chrome 底 + 白字 + `shadow_2` | 统一材质，不逐处自定义 |

规则：

- 玻璃只用于浮层，不用于列表、表单和长内容卡；不要玻璃叠玻璃。
- 壁纸可见但不干扰阅读：浅色遮罩约 72%，深色约 68%；壁纸细节强时提高遮罩，不降低文字对比度。
- 正文只出现在实心面或页头玻璃上，不直接压在壁纸上。
- 阴影只保留三级；行默认轻阴影，hover/拖拽升一级；chip 与文本动作不投影。
- 主操作只有一个；次级操作用浅底或文本动作，不与主按钮抢填充。

**底板与边界（唯一规则）**：元素自身有可见底色时，同时设置 1px 边界；边界颜色按语义配对，没有底色的不加。

- 中性：`control_bg` / `control_border`。
- 品牌选中或主 tonal：`brand_tint` / `brand_tint_strong`。
- 危险 tonal：`danger_tint` / `danger_border`。
- 会话 chrome：`chrome_control_bg` / `chrome_control_border`、`chrome_danger_bg` / `chrome_danger_border`、`chrome_accent_bg` / `chrome_accent_border`。
- 身份/状态图标底板：页面内用 `control_border`，会话 chrome 内用 `chrome_border`。

没有底板的元素不设边界：`TextAction`、页签、品牌 Logo、Moonlight 封面、纯文字。卡片与行自身已有边界，内部不再叠第二层。

这不是“控件 / 图标”两套代码类型；代码只以 token 配对与 `ControlDisc.discBorder` 落实同一规则。

## 5. 字体与文案

### 5.1 字号阶梯

产品页面只用 `20 / 18 / 16 / 14 / 12 / 10`；不使用 11/13/15/17，也不新增 9。

| 角色 | 字号/行高 | 字重 |
|---|---|---|
| 品牌/覆盖层标题 | 20 / 26 | 600 |
| 标准页标题 | 18 / 24 | 500 |
| 行/卡片标题 | 16 / 22 | 500 |
| 正文/表单 | 14 / 20 | 400/500 |
| 紧凑控件/说明 | 12 / 16–18 | 400/500 |
| 徽标/极小标注 | 10 / 14 | 500 |

- 标题行高约 1.3×，正文约 1.4×。
- 数字（遥测、滑块值、尺寸）使用等宽数字并右对齐。
- 只有品牌/覆盖层标题使用 600；不使用 700。
- `GfxReplayPage` 是开发页，不纳入产品字号契约。

### 5.2 文案密度

说明文字不是设计素材。先删减，再排版。

- 每条说明只回答“这是什么/有什么后果”，不重复标题，不解释显而易见。
- 单条说明控制在一行；超过就改写或移到帮助/tooltip。
- 同一区块只保留一条说明；其余信息进高级设置或提示。
- 不用“本机/远端/当前”这类冗词；不用长条件句；不用括号补充第二层信息。
- 只有真实风险、能力限制或破坏性后果使用警告/危险色；普通说明用 tertiary。
- 不靠缩小字号容纳文案；字号是层级，不是排版补丁。

## 6. 几何

几何使用一套共享尺度，组件只取需要的层级：

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32；页面 24（窄窗 16），区块 16，行内 12，控件 8，列表间距 8。
- 圆角：4 / 8 / 10 / 12 / 14 / 20 / full；内容卡与状态卡 20，行/工具条/磁贴 14，输入 10，按钮 12，chip 8。
- 内容最大宽 720；编辑页卡片内边 28，其余 24。
- 热区最小 44；视觉 36 圆钮扩到 44；chip 视觉 32、热区 40。
- FAB 56；输入紧凑 40、表单 46；状态卡最大 360、宽 90%；工具条行高 48。

组件内部的局部取值写在组件常量里；本文只保证尺度一致，不逐组件复述。

## 7. 图标

- 统一 24×24 网格，视觉线宽 2，圆头圆角。
- 单色图标必须是 fill-only SVG，运行时用 `fillColor` 着色；线宽烘焙成 `stroke` 会导致无法着色。
- 尺寸只用 16（行内）、20（紧凑）、24（标准）、32（页头/空状态）。
- 默认 `icon_secondary`；主要/激活 `icon_primary` 或品牌文字色；品牌底上白色；危险动作用危险色。
- 彩色例外只有应用图标与协议标记；它们不需要 `resources/dark/media` 副本。
- 单色图标不维护深色副本；深色跟随 `$r('app.color.icon_*')`。
- 彩底标记使用 40/44 方形、圆角 10/12，内部白色字形；不描边、不加内阴影。

## 8. 组件模式

结构与交互见 [`ui-framework.md`](ui-framework.md) §4；这里只定义视觉模式。

- **内容卡/行**：实心面 + 1px 描边 + 轻阴影；hover 升一级；拖拽再升一级并轻微放大。行与行之间用间距分开，不再叠列表外框或分隔线。
- **交互件**：主按钮品牌填充；次按钮用 `control_bg` + `control_border`；文本动作透明；圆钮承载单图标；未选 chip 用 `control_bg`，选中用浅品牌底。禁用统一 40%，同时关闭 hover 与聚焦。
- **FAB**：与卡片按钮共用同一套 tonal 逻辑，只放大尺寸并加阴影。主操作用半透明品牌浅底 + `brand_tint_strong` 描边 + `brand_text` 图标，与卡片启动按钮同一 token 对；次操作用半透明中性底 + `control_border` + `icon_primary`，与卡片应用按钮同一 token 对。hover/press 只在该语义对的加强档内变化，不使用白图标 + 固定主题填充。
- **表单**：输入框浅底 + 描边；标签次级文字，提示 tertiary，错误危险色，能力限制警告色。字段间距大于行内间距。
- **状态视图**：空/加载/错误使用同一状态卡结构；会话覆盖层用暗玻璃状态卡，页面内状态卡用实心面。
- **提示与确认**：配对、主机选择、WoL 帮助、确认、通知统一走 `PromptDialog`；标题 20/600，说明 14/20 次级，按钮 44/12，取消在左、确认在右，危险确认用危险浅底。Toast 统一暗色 chrome 底、白字与阴影。
- **会话 chrome**：暗玻璃、白色主文字、次级白遥测、等宽数字；按钮用中性/危险/激活三档 tonal，不裸放文字；进度条用 accent 填充、半透明白轨道。
- **协议差异**：RDP 与 Moonlight 只在图标、页签、运行徽标上分色；其余组件共用同一套中性色与品牌色。

## 9. 动效

- 时长：press 100ms，hover/颜色 160ms，浮层出现 200ms、消失 160ms，覆盖层 280ms。
- 曲线：默认 `FastOutSlowIn`，出现 `EaseOut`，消失 `EaseIn`。
- hover 以背景叠色为主；圆钮、FAB、磁贴最多 1.02；行、chip、页签不缩放。
- press 圆钮/FAB/磁贴 0.96；行与 chip 只换底色。
- 浮层出现用透明度 + 0.98 缩放；不使用弹跳、脉冲、呼吸或无限装饰动画。
- 工具条滑入/滑出 180ms；唤出提示淡入 140ms。
- 系统开启“减少动效”时，去掉缩放与位移，只保留透明度。

## 10. 响应式

- 断点：<840 紧凑，840–1280 标准，>1280 宽屏。
- 页面边距 24，窄窗 16；内容卡始终最大 720 并居中；表单不拆两列。
- 页头 trailing 最多 3 个动作，超出进菜单；窄窗只保留主要动作。
- 工具条按设置百分比居中；窄窗优先减少次要遥测与文案，不压缩字号、不缩小热区。
- 磁贴按 108 宽自动换行，右侧为 FAB 预留空间；对话框最大 480，状态卡最大 360。

## 11. 可访问性

- 正文对比度 ≥4.5:1；大字、图标、控件边界 ≥3:1。
- 关键后果不用 tertiary；tertiary 只承载非关键说明。
- 可点击件热区 ≥44×44；chip 热区 40；推荐 48。
- 焦点始终可见：系统焦点框优先；自定义件补 2px 品牌色外框，偏移 2。
- 状态不只靠颜色；文字随系统字体缩放时行高用 `minHeight`，单行标签配省略，说明最多两行。
- 壁纸上不直接放正文；深色跟随系统；测试高对比度文字模式。

## 12. 不采用

- 11/13/15/17 号字、9 号徽标。
- hover 1.06 / press 0.9 的移动端弹性。
- 白字压在图标蓝上作主按钮。
- 图标 SVG 内烘焙颜色、为单色图标维护深色副本。
- 列表、表单、长内容卡使用毛玻璃。
- 满屏渐变、彩色阴影、霓虹发光、所有控件胶囊化。
- 用缩小字号容纳 AI 味长说明。
- 菜单保持系统默认；提示/确认/通知与 Toast 不逐处手写容器，统一走 `PromptDialog` 与统一 Toast 材质。

## 13. 硬约束

- 颜色只通过 `$r('app.color.*')` 引用；`.ets` 中不出现十六进制颜色。
- 单色图标只放在 `resources/base/media/`；`resources/dark/media/` 只允许彩色例外。
- 产品页面字号只用 20/18/16/14/12/10；说明文字先删减，再排版。
- 会话工具条与状态卡始终使用 `chrome_*`，不跟随系统深浅。
- 玻璃只用于页头、会话工具条、状态卡；内容面与提示窗保持实心。
- 提示/确认/通知统一走 `PromptDialog`；Toast 统一暗色材质；菜单保持系统默认。
- 可点击件热区 ≥44×44；chip 热区 40。
- 安全控件（`PasteButton` 等）只使用其通用属性；边框用 `borderWidth` / `borderColor` / `borderStyle`，不要用 `.border()` 简写。
- `build_project` 通过是视觉改动的底线；涉及上屏/硬件加速的观感只在真机验证（见 [`present.md`](present.md)）。
